# Contributing to Blackpeter Core

Thank you for your interest in contributing to Blackpeter Core! We welcome contributions from everyone. Here are some guidelines to help you get started.

## Getting Started

1. **Fork the repository**: Create a personal copy of the project by forking the [Armor-Network/blinkhash-core](https://github.com/Armor-Network/blinkhash-core) repository.
2. **Clone your fork**: Clone your forked repository to your local machine.
   ```bash
   git clone https://github.com/<your-username>/blinkhash-core.git
   ```
3. **Create a branch**: Create a new branch for your contribution.
   ```bash
   git checkout -b my-feature-branch
   ```

## Making Changes

Make your changes in the code, documentation, or tests. Follow the existing style of the code and ensure that your contributions fit naturally within the project.

## Testing

Before submitting your contributions, please ensure that all tests pass. Run the tests using the following command:
```bash
git test
```

## Submitting Contributions

1. **Commit your changes**: Make sure to write clear commit messages that explain your changes.
   ```bash
   git commit -m "Description of your changes"
   ```
2. **Push your changes**: Push your changes to your forked repository.
   ```bash
   git push origin my-feature-branch
   ```
3. **Create a pull request**: Go to the original [Armor-Network/blinkhash-core](https://github.com/Armor-Network/blinkhash-core) repository and click on "New Pull Request". Select your branch and describe the changes you made.

## Security Contacts

For security vulnerabilities, please contact the maintainers directly instead of creating a public issue. You can email security@armor-network.com.

## Communication

For communications, please use the designated project channels rather than mailing lists. You can find discussions and announcements on our Discord channel or other community platforms.

Thank you for your contributions! Together, we can make Blackpeter Core even better!
